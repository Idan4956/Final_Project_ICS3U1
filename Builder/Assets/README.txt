INSTRUCTIONS: Add all of your media and resources you will need for your game in the folders below

+ Audio		  <-- All in-game audio organized in here
|   |
|   + Sounds	  <-- Store sound effects in ONLY .wav format (see class instructions for conversion help)
|   |
|   + Music 	  <-- Store songs in EITHER .ogg or .mp3 format (see class instructions for conversion help)
|
+ Images	  <-- All in-game graphics organized in here (including still images, animations, etc.)
|   |
|   + Sprites	  <-- Store game object and animation (sprite sheet) images in ANY of .png, .jpg/.jpeg, .bmp, .webp, .gif (not animated)
|   |
|   + Backgrounds <-- Store background (can be animated sprite sheets) in any of the image formats listed above
|
+ Fonts		  <-- Store downloaded .ttf and .otf font files here as well as CREATE your own SpriteFonts that use the fonts here (see README)
|
+ Levels	  <-- Store any level data for your game (if any), typically these will be in either .txt or .csv format
|
+ Other		  <-- Store any other data files needed for your game here (if any), if it is an uncommon type then Builder changes may be needed
